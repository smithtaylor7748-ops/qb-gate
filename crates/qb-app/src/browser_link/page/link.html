连接 QB Gate 浏览器助手

正在等这个浏览器里的「QB Gate 浏览器助手」插件认领这次连接…

不需要复制或粘贴任何东西，通常一两秒就好。

插件已经看到这次连接，正在向 QB Gate 确认…

已连接。

可以关掉这个页面了。以后 QB Gate 重新打开，插件会自己连上，不用再来这里。

这个浏览器里没有检测到「QB Gate 浏览器助手」插件。

  1. 在地址栏打开 chrome://extensions（Edge 是 edge://extensions）。
  2. 打开「开发者模式」。
  3. 点「加载已解压的扩展程序」，选 QB Gate 面板「浏览器助手」页里「打开插件文件夹」指的那个文件夹。
  4. 装好后回到这个页面按 F5 刷新，连接会自动继续。

已经装了、只是装在另一个浏览器或另一个用户资料里？在那个浏览器里打开这个页面的地址即可； 或者回到 QB Gate 面板，把那个浏览器设成默认浏览器后再点一次「连接浏览器」。

这次连接几分钟后失效。过期了就回到 QB Gate 面板再点一次。

这次没连上。

处理完之后按 F5 刷新这个页面，连接会自动继续。

这次连接已经失效（超时，或者已经被用过）。

回到 QB Gate 面板，再点一次「连接浏览器」。

连不上 QB Gate。

面板可能已经退出，或者这次连接已经结束。打开 QB Gate 面板，再点一次「连接浏览器」。

这个页面要从 QB Gate 面板里打开。

回到 QB Gate 面板，在「浏览器助手」里点「连接浏览器」。

这个页面由你电脑上的 QB Gate 提供，只在本机（127.0.0.1）能打开，不经过互联网。
