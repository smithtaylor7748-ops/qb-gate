# 已知问题与待修

按「修不修得了」分三档。**第 1 条是安全问题，优先级最高。**

---

## 一、要修的

### 1. ★ 旧版本留下的 `Everyone:(F)` 残留，现在的解锁路径修不掉

**症状。** 某个 `claude.exe` 上挂着一条**显式**的 `Everyone : 完全控制` ACE
（SDDL 里是 `(A;;FA;;;WD)`）。本机任何账户、任何进程都能替换掉这个可执行文件。

**怎么来的。** 早期版本的 `unlock` 会把 DACL 写成空指针（NULL DACL，
含义是「不做任何访问检查」）。这个状态后来被固化成了一条显式的 `Everyone:(F)` 条目。

**为什么现在修不掉。** `gate/acl.rs` 的 `unlock()` 只在 `cur.dacl.is_null()` 时
走 `restore_inherited()` 自愈 —— 它认得出「门完全敞开」，认不出「锁坏了但门还挂着」。
走到正常路径后，过滤器只剔除 `is_our_deny(e, sid)`，把 `Everyone:(F)` 当成使用者
自己设的条目原样保留。于是**每一次上锁 / 解锁都把这个洞重新写回去一遍**。

**怎么查。**

```powershell
(Get-Acl "$env:LOCALAPPDATA\AnthropicClaude\claude.exe").Sddl
# 出现 (A;;FA;;;WD) 就是中了；带 ID 标志的 (A;ID;...) 是继承来的，不算
```

**手工修。**

```powershell
icacls "$env:LOCALAPPDATA\AnthropicClaude\claude.exe" /remove:g "*S-1-1-0"
```

**该怎么改。** 在 `unlock()` 的过滤器里，除了 `is_our_deny`，再剔除掉
「授予 `S-1-1-0`（Everyone）完全控制的显式条目」，并补一条回归测试：
构造一个带 `Everyone:(F)` 的文件 → 上锁 → 解锁 → 断言那条 ACE 已经不在。
注意只剔除**显式**条目，继承来的不能动。

### 2. 没有单实例保护

面板可以被开出好几个，于是好几个看门狗同时跑。应当在启动时抢一个命名互斥体，
已经有实例就把已有窗口拉到前台然后退出。

`actions/checkout@v4`、`actions/setup-node@v4`。升到 v5 即可，

### 4. 安装器自己建的桌面快捷方式在中文路径下是坏的

`WScript.Shell` 存不了非 ASCII 路径，中文桌面会被它变成 `??`，
存出来的 `.lnk` 目标是空的。

目前的绕法是让用户跑一次 `scripts/setup-desktop.ps1`（它先在纯 ASCII 临时路径建好再搬）。
**应当把这个绕法做进 NSIS 安装脚本里**，而不是让用户自己发现。

## 二、修不了的（设计使然，不是缺陷）

这三条都是同一类：Windows 的执行锁挡得住「正常的那条路」，挡不住绕开它的路。
要彻底堵死需要 AppLocker / WDAC，不在本项目范围内。

| 缺口 | 说明 |
|---|---|
| `%LOCALAPPDATA%\AnthropicClaude\app-<版本>\claude.exe` | **不能加 Deny ACE** —— 一加，桌面端开新窗口就崩。进那个目录直接双击能绕开启动门禁，20 秒内会被看门狗收掉（前提是当时有看门狗在跑） |
| npm 装的 Claude Code / Codex | `claude.cmd` / `codex.cmd` 是批处理，由 `cmd.exe` 读进去执行，真正跑的是 `node.exe`。执行锁管得住这个命令本身，管不住直接去调它内部的 node 脚本。界面上如实标「执行锁管不到」 |
| MSIX 方式装的桌面端 | `WindowsApps` 下的文件改不了 ACL，也没有存根可以拉起它。看门狗在出口 IP 不对时仍会关掉它 |

> **所以：本项目提供的不是安全边界，不要把它当强制访问控制用。**

## 三、没有实机验证过的

作者本机什么都装在 `~\.local\bin`，很多路径分支从来没走到过。
这些都有临时目录里的假机器单测，但**没有在真机上跑过**：

- 面板托管的真下载安装（Claude Code / Codex）
- 托管升级
- 改托管目录后的一键迁移
- 清外部副本
- 托盘切换账户
- Chrome 清空重装
- MSIX 版桌面端、编辑器扩展里的副本 —— 这两类的布局是**按安装机制推的**，作者本机没有

总览页有七项只有真数据才验得到（槽位翻页、自动落在激活页、两步失败要分开报、
激活槽位过期、磁贴进度态、日志时间线、残留副本变红）。

碰到这些路径出问题，**先怀疑是这里没验过，而不是怀疑自己用错了**。
