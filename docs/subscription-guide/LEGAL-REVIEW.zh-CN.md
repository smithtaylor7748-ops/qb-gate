# 订阅引导与 ClaudeGate 发布风险初查

审查整理：2026-09-10。对象包括新建引导模块、用户提供的 2026-09-09 项目档案，以及桌面项目少量现有源码的只读抽查。项目正在被其他 AI 修改；本结论不是完整代码审计或正式法律意见。正式公开含账号桥接的版本前，建议由熟悉软件与跨境服务的中国律师结合最终实现复核。

## 结论

**可以先把这个独立引导作为候选开源内容审阅，但不能据此断言整个 ClaudeGate “没有法律风险”。** 引导采用本人购买、真实付款资料、原创示意和出处链接，没有实现收款、账号交易或网络绕过。仍有三类优先事项：主项目的订阅凭证桥接、品牌名称、第三方软件许可。境内法律、服务合同和知识产权是不同问题；没有触犯某一项不等于满足其他项。

“MIT”“本地运行”“免费开源”“仅供学习”“手动切号”都不是统一免责条件。用户档案里的合规定位是项目自述，不是外部法律结论。

## 与中国境内法律有关的边界

### 1. 教程内容与网络接入

国际联网的信道与接入有专门要求。本指南不讲如何绕过接入限制，不提供相关服务购买链接，不教伪造身份、地址或设备信息。支付宝选择活动目的地只用于浏览商户，不能写成更改真实居住地或付款地区的方法。提供普通订阅操作资料不能证明使用者的所有网络接入行为均合法。[国家行政法规库：国际联网管理暂行规定，2024 年修订，第 6、8、10 条](https://xzfg.moj.gov.cn/front/law/detail?LawID=1713)

本次未逐一核实发卡行、每笔跨境交易和每个商户的资质或适用限制；因此不写“国内银行卡全部可用”“支付宝可付就必然合规”。购卡、充值和订阅应使用本人真实资料，并以发卡行、商家及收款平台的要求处理拒付或退款。

### 2. 版权与素材

适当引用有条件，不是写上作者名字就能无限搬运。真实截图可能同时含有软件界面、商标、用户资料和摄影作品；整段视频搬运风险更高。本包选择原创插图和原网页链接，未给外部作品套用 MIT。[《中华人民共和国著作权法》2020 年修正，第 24 条](https://zscqj.beijing.gov.cn/zscqj/zwgk/flfg18/436481084/index.html)

### 3. 个人信息

新模块只用内存记录勾选，没有收集账号、IP、卡号、订单，也不自动加载第三方媒体。用户主动打开第三方网页后，由对应网站处理请求。主项目若另有 IP 查询、遥测、错误上传或云端同步，应核实处理依据、必要性、告知内容及适用的跨境规则，不能直接沿用“本地工具所以没有个人信息处理”的表述。[《个人信息保护法》第 13、17、38、39 条](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)

## 本包采用的发布措辞

|避免的表述|采用的表述|
|---|---|
|国内卡必过、包订阅成功|有网上个案；需分别核对绑卡、首扣和续费|
|必须把时区语言全改成 IP 地区，否则封号|保持真实设置稳定，核对时间与实际时区，检查 IP 定位差异；语言偏好不应当作防封规则|
|Pockyt 是 Apple 官方充值小程序|Pockyt Shop 是独立商家；入口与商品依据官方商家页及社区记录|
|精选全网最新、已全程验证的视频|2026 年检索到的参考链接；索引核对，未完整播放审核|
|本人会员可以直接当任何插件的 API|会员与 API 计费／授权不同；桥接需要单独核实|
|开源免费，绝对合法|独立内容已做风险初查；最终软件仍需按实际功能审查|

Anthropic 公开说明会通过 IP 等信息推断大致位置，但未公开“语言与 IP 同语种就防封”的公式。[Claude 位置数据说明](https://privacy.claude.com/en/articles/11186740-does-claude-use-my-location)

## 当前审查没有覆盖什么

未完成整个 Rust 工程或外部桥接源码审计；未检查 Git 历史中的密钥、全部依赖许可证、签名发行包、遥测请求、税务或商家资质；未对真实账号进行登录、付款或退款操作。未判断所有服务地区及个案合同的可执行性。动态提供的消费者条款可能因地区显示不同版本，应按用户实际适用版本核对。

可以先将本包独立存放和审阅。正式合并发布时，应补齐上述与真实实现直接相关的检查，特别是桥接、凭证、品牌和再分发许可；无需为普通图文阅读增加收集身份信息或强制“同意免责”弹窗。
