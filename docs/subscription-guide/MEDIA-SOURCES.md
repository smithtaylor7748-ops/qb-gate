## 页面里的图从哪里来

六步手机界面、银行卡与礼品卡装饰图、两个视频封面都是本包用 JSX / CSS / 内联 SVG 绘制的原创示意。每幅均标注“原创界面示意 / 非官方截图”或“原创封面示意 / 非视频截图”。文字与价格以步骤内容为准，未画出虚假已付款收据。

这些示意图会随服务和渠道切换。没有远程字体、热链截图、外部视频播放器或自动请求第三方缩略图；只有用户点击链接才访问第三方网站。源页面图片保留原权利，标注来源本身不是再分发许可。

如果未来希望把真实截图放进软件，应取得明确许可或逐一评估适用的引用条件，标注截图日期与版本，遮去姓名、账号、订单号、卡号和兑换码。不要把来源站的全部文章或视频复制进仓库。
