## 口径（使用者定的）

- 不提任何特定国家、货币或发卡行；「国内」指 Anthropic 与 OpenAI **两家都正式提供服务**的国家和地区，以两家官方名单为准。
- 免税州地址与地址生成器只作**格式参考**，填表用本人真实地址；这类提醒在页面上一律红字。
- 中转站的每一条坏处都标明是报道、研究、官方条款还是使用者反馈；未经官方证实的写「未证实」。
- 不推荐任何虚拟卡 / 卡商；接码平台只作为社区做法提及，并注明第三方自负。
- `Subscription.test.tsx` 里有一条禁词守卫盯着渲染出来的文字，文案改回去当场红。

## 购买步骤里的事实

- Apple ID 已改名 Apple 账户，注册页 account.apple.com（原 appleid.apple.com 跳转过去）。
- Apple 礼品卡只能在购买国家或地区兑换（support.apple.com/118285）；账户余额可付订阅（support.apple.com/118245）；退款走 reportaproblem.apple.com。
- Google Play 礼品卡只能在购买国兑换、付款资料国家须一致（support.google.com/googleplay/answer/7431675）；卸载 ≠ 退订（answer/7018481）。
- Anthropic 消费者条款：款项默认不退，少数地区 7 天窗口；禁止共享账号登录信息。
- Anthropic 2026-01 起服务端限制订阅 OAuth 只认官方 Claude Code，02-19 写进条款，04-04 全面执行（The Register / GIGAZINE）。
- 地址生成器 usaddressgen.com 自己写明：「测试地址不能作为免税证明，真实交易仍应使用真实所在地。」页面原文引用。
