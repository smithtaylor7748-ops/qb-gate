QB Gate 浏览器助手

三步用起来

  1. 在 QB Gate 面板点「连接浏览器」

    打开电脑上的 QB Gate 面板，进入「扩展 → 浏览器助手」，点「连接浏览器」。 面板没在运行时插件连不上它，这一步必须在面板里点。

  2. 浏览器里会自动打开一个确认页

    页面标题是「连接 QB Gate 浏览器助手」。插件会自己完成连接，不用复制或粘贴任何东西， 看到「已连接」就好。以后面板重新打开，插件会自己连上，不用再来一次。

    确认页打开在别的浏览器里？把那个页面的地址粘到装了这个插件的浏览器里打开即可（几分钟内有效）。

  3. 开启保护

    开启后，只有 QB Gate 确认出口 IP 没变时，下面这些受保护网站才能打开；出口一变、QB Gate 断开或查不到， 它们会立刻被拦下，已经打开的页面也会换成说明页。其他网站、其他标签页一律不动。

    它是什么、不是什么

    • 是：按网站拦截。保护开着时，受保护网站只在 QB Gate 核实出口之后才放行；浏览器重启、插件后台重启、面板没开，都先拦着。
    • 是：可以随时在插件弹窗里「暂停保护」，暂停就撤掉全部拦截规则。
    • 不是：代理或 VPN。插件不改你的网络、不转发任何流量，也不改浏览器设置。
    • 不是：整机防护。只管装了这个插件的这一个浏览器资料；别的浏览器、别的资料、别的程序不管。
    • 出口 IP 由 QB Gate 面板探测。如果这个浏览器单独设了代理，它真正走的出口可能跟面板探测到的不一样。
