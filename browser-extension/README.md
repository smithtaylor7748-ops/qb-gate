# QB Gate 浏览器助手

Based on QB Gate, Copyright (C) 2026 smithtaylor7748-ops.
Source code: https://github.com/smithtaylor7748-ops/qb-gate

跟电脑上的 QB Gate 面板联动：**QB Gate 没确认出口 IP 时，拦下受保护的网站**（默认是 Claude 官方网页），其他网站照常。
附带三个小功能：检查这个浏览器的环境、中转站「查套路」用浏览器里已登录的账户、读取中转站公开价格。

需要 Chrome 或 Edge 116 及以上，以及带「浏览器助手」（协议 2）的 QB Gate。旧版 0.1.0 插件连不上新面板。

## 安装

1. 打开 `chrome://extensions`（Edge 是 `edge://extensions`），打开「开发者模式」。
2. 点「加载已解压的扩展程序」，选这个文件夹（QB Gate 面板「扩展 → 浏览器助手」里「打开插件文件夹」指的那个）。
3. 装好会自动打开引导页。插件的 ID 应当是 `dffmajnemniojfblgfhenndeeelbjgoh`。

Chrome 启动时可能提示「停用开发者模式下的扩展程序」，点「保留」即可。

## 连上 QB Gate

在 QB Gate 面板「扩展 → 浏览器助手」点「连接浏览器」。浏览器会打开一个「连接 QB Gate 浏览器助手」的确认页，
插件自己完成连接，**不用复制粘贴任何东西**，看到「已连接」就好。以后面板重新打开、浏览器重启，插件都会自己连回来。

- 确认页打开在了别的浏览器里：把那一页的地址粘到装了插件的浏览器里打开（几分钟内有效）。
- 面板提示「一键重连」（它原来的端口被别的程序占了）：点它，再在装了插件的浏览器里打开弹出来的确认页。
- 一台电脑上几个浏览器资料都可以装、各连各的（最多 8 个）；面板里能单独解除任何一个。

## 保护：是什么、不是什么

**是**：

- **只拦受保护的网站**。名单默认是 Claude 官方网页用的 `claude.ai`、`claude.com`、`anthropic.com`、`claudeusercontent.com`
  （各连同子域名），在插件的设置页增删。其他网站、其他标签页一律不动。
- **保护默认关**。在弹窗或引导页点「开启保护」才生效；之后只有 QB Gate 核实出口没问题，受保护网站才能打开。
- 这些情况会拦：出口变了（白名单里换一个 IP 也算）、查不到出口、IP 锁被手动关闭、IP 锁或网络设置变了、检测过期、
  面板退出 / 崩溃 / 没开 / 连不上、面板一阵没回话、这个浏览器的网络或代理刚变过（等面板复查）。
- 已经打开的受保护页面会换成一页说明，写清为什么拦、下一步点哪里；放行之后自动回到原来的页面。
- **浏览器重启、插件后台重启的那一刻起就拦着**，直到这一次重新核实过出口。
- 出口变了，要你确认之后点「重新放行」；别的原因插件会按你上次放行的那个出口自动再核，核过就自己恢复。
- 随时能在弹窗里「暂停保护」：暂停就撤掉全部拦截规则。删除插件也一样全部撤销。

**不是**：

- 不是代理或 VPN：不改你的网络、不转发任何流量、不改浏览器设置。
- 不是防火墙：出口变了之后，到面板下一次复查出来之前（最长约 5 秒再加探测的时间）已经发出去的请求撤不回。
- 不是整机防护：只管装了它的这一个浏览器资料。别的浏览器、别的资料、别的程序不管；隐身窗口要在扩展详情里打开「在无痕模式下启用」才管。
- 出口是面板探测的：这个浏览器单独设了代理或 PAC 时，它真正走的出口可能跟面板探测到的不一样。

## 每个权限为什么要

| 权限 | 用来做什么 |
|---|---|
| `declarativeNetRequest` | 装「拦截」与「放行」两条规则，只对受保护网站名单上的域名。安装时浏览器会提示「屏蔽任何网页上的内容」—— 实际只装名单上的 |
| `storage` | 在这个浏览器里存：和 QB Gate 的配对（编号、口令、端口）、受保护网站名单、上次放行的出口 |
| `alarms` | 每 30 秒叫醒一次插件后台：连不上时重连，复核放行有没有过期 |
| 主机权限 `http://127.0.0.1/*` | 连本机的 QB Gate；在面板打开的确认页上完成连接 |
| 主机权限 `claude.ai` 等四个域名 | 触发拦截时找到并切换已经打开的受保护页面（不读页面内容） |
| `activeTab`、`scripting` | 只在你点「连接已登录账户」时，读当前中转站页面里的登录信息 |
| `cookies` | 同上，读这个中转站的 `session` Cookie（New API 站点） |
| `privacy`、`proxy` | 只读：浏览器检查里报告 WebRTC 策略与代理模式；代理设置变了时先拦、请面板复查 |
| 可选：任意网站 | 只在你给某个中转站读账户 / 价格、或在设置页加受保护网站时，浏览器逐个问你 |

没有 `tabs`、`webNavigation` 权限，也不把任何页面开放给网页（`web_accessible_resources`）—— 网页没法借此探测你装了这个插件。

## 受保护网站

在插件设置页（弹窗里「管理」或「设置」）增删。填域名就行，子域名一起保护；不能填 IP 或本机地址（那会把插件自己和 QB Gate 的连接也拦掉）。
加新网站时浏览器会问一次能不能访问它：允许之后，触发拦截时已经打开的那些页面才能换成说明页；不允许也照样拦，只是看到的是浏览器自带的「已被扩展程序屏蔽」页面。
名单只存在这个浏览器的插件里，QB Gate 面板看不到。

## 扩展 ID

`dffmajnemniojfblgfhenndeeelbjgoh`，由 `manifest.json` 里的公钥固定，所有浏览器资料、重装之后都一样。它是公开的、**不是密码**：
认人靠的是连接时配对的长期口令和每次连接的证明。

## 附带功能

- **检查当前浏览器**：在这个浏览器里打开 QB Gate 的一次性检测页（语言、时区、字体、WebRTC 与请求头），另外只读 WebRTC 策略和代理模式 / 控制方，
  不传代理地址、密码或 PAC 内容。结果回到面板，不进 IP 锁判定。
- **连接已登录账户**：在 New API 或 Sub2API 站点登录后，选好 QB Gate 里对应的站点与类型再点。只读这个页面列明的登录存储字段与同一站点的 `session` Cookie，
  不读密码或刷新令牌；交给本机 QB Gate 验证余额与账单接口后加密保存，用于「查套路」。不创建 API Key、不调用收费模型。
- **读取公开价格**：不带登录地请求 New API `/api/pricing` 或 Sub2API `/api/v1/model-plaza`。公开价相对官方价的倍数只是报价对照，真实收费倍率仍由「查套路」核对实扣账单。
