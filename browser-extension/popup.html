开启后，出口 IP 变化、IP 锁不放行、断网或与 QB Gate 失联，将关闭此 Chrome 资料中的全部窗口，未保存的内容可能丢失。其他资料和后台进程不在关闭范围内。

巡检使用 QB Gate 的出口；Chrome 独立代理或 PAC 的出口可能不同，代理或网络状态变化也会触发关闭。 这是检测后关闭窗口，不是防火墙断网。关闭存在检测延迟；重开 Chrome 后需重新开启保护。QB Gate 需保持运行。

增强浏览器检查

在当前 Chrome 检测语言、时区、字体与 WebRTC，并补充实际 WebRTC 策略和代理控制状态。结果显示在 QB Gate「检查」。

中转站账户与公开价格

请先在当前页面登录对应站点。点击连接仅读取此站点的会话与账户标识，交给本机 QB Gate 验证并加密保存，用于「查套路」；不读取密码或刷新令牌。

公开价格使用未登录请求。公布价相对官方的倍数仅作价格对照，真实收费倍率仍由「查套路」核对实扣账单。

连接与配对
