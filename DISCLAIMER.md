## 4.5 门禁的代价：执行锁、看门狗、会话内门禁与国家白名单

### 执行锁与看门狗

- 执行锁给 Claude 程序与 GPT（Codex）程序的每一份副本加 NTFS
  `Deny ExecuteFile` 规则（v0.25.0 起 GPT **默认纳入**门禁，与 Claude 同一套规则：
  桌面端起之前验出口 IP、起来之后归看门狗管；可在「IP 锁」弹窗里把 GPT 移出）。**上锁后双击程序会被系统拒绝执行**，这是设计如此，
  必须走面板入口。
- 门禁放行期间，看门狗每 15–20 秒复核一次出口 IP。**出口 IP 不在白名单、国家不合格、
  或者查不到出口 IP 时，第一轮就上锁并关闭受门禁管理的 Claude 会话**，
  Claude Code 与桌面端都一样，没有宽限期。这是使用者明确选定的严格档
  （「宁可错杀不可放过」）。
- **代价必须说清楚：** VPN 重连、DNS 抖动、切换节点、或者几个 IP 查询服务同时限流，
  都会**直接关掉你正在用的 Claude Code 和桌面端，未保存的对话会丢**。
  「网络恢复后重新放行」（默认开启）只会在复核通过后恢复放行，
  **不会**重新启动已经被关掉的会话。
- 把误杀压到最低的办法是三源并发探测（ippure / Cloudflare / ipinfo，任一家答上来
  就算查到）—— 所以「查不到」意味着三家全挂，而不是某一家抽风。
  但这只是降低概率，不是消除。

### 会话内门禁（装进 Claude Code 的 hook）

这一项**默认是关的**，打开之前请把代价读完。

它在每次请求发出前验一遍门禁，判不过就拦下这一次请求。**它是 fail-closed 的**：

- 出口 IP 不在白名单 → 拦；
- 查不到出口 IP → 拦；
- **面板没在跑（门禁裁决超过 90 秒没刷新）→ 也拦**。

也就是说，启用之后，**不开面板就用不了 Claude Code**。这是「宁可错杀不可放过」
的直接后果，由使用者自己选定。

三条自救路径，任何一条都够把自己放出来：

1. 在面板里停用会话内门禁（面板自身不受 hook 影响，永远打得开）；
2. 被拦时命令行里会印出手动解除步骤；
3. 直接编辑当前槽位的 `settings.json`，删掉 `hooks` 里带 `_qb_gate` 标记的两段。

面板在**白名单为空时拒绝启用**这一项 —— 那等于每一次请求都会被拦。

### 国家白名单

这一项**默认不启用**。启用之后，出口 IP 归属的国家不在名单里，门禁一律判不合格：
看门狗会收进程、会话内门禁会拦请求、「加入当前 IP」也会被拒。

**代价：GeoIP 不准会误杀正在进行的会话。** 面板向三家（ippure / Cloudflare /
ipinfo）问国家，三家说的不一样时**按最严的算，判不合格**，冲突原文写进日志。
这意味着一次 GeoIP 数据打架就可能让你正在跑的会话被收掉 —— 日志里那一行会写清
是哪一家在胡说，但会话已经没了。

**名单为空 = 这一层不启用，不是全拒。** 这是刻意的：全拒会在使用者还没来得及
配置时就把他关在门外。

面板给的预设**不是任何服务商的官方完整清单**，面板也不知道那份清单。
它们只是省得手打的起手式，应当自行对照服务商公布的支持地区核对后增删。
**国家白名单只约束你自己的电脑，不代表你所在地区可以使用某项服务。**

  线路的 Key 换了，面板会把新 Key 写进去；删掉那条线前会先改回经本机路由。改回经本机路由时那一格换回占位串。
  面板界面上不显示这把 Key；重开桌面端才生效。
- **Gemini CLI / Grok Build 的中转环境**（2026-10-25 起）：Gemini CLI 用面板自己的目录（`GEMINI_CLI_HOME`），
  不碰你官方 Gemini 的登录；Grok Build 会在 `~\.grok\config.toml` 里写一个指向本机路由的 `qb-gate` 模型（占位 Key），别的设置不动。
- **跳过 Claude Code 首次确认**（2026-10-25 起）：在你点「跳过」之后，在那一份 `.claude.json` 里写 `hasCompletedOnboarding = true`。
  默认只列中转环境那一份；官方默认目录（`~\.claude.json`）和官方槽位每一行要你自己点才改。「恢复」只撤面板设的那个，
  你自己走完首次确认、Claude Code 记下的不动；别的字段一个不改。
- **VS Code 插件联动**（2026-10-25 起，VS Code / Insiders / Cursor / Windsurf / VSCodium）：在你点「联动」之后，往那个编辑器的
  用户设置（`%APPDATA%\<编辑器>\User\settings.json`）的 `claudeCode.environmentVariables` 里加两条（`CLAUDE_CONFIG_DIR` 指向中转环境目录、
  `ANTHROPIC_AUTH_TOKEN` 是本机路由的占位串，**不是你的 API Key**），并把 `claudeCode.disableLoginPrompt` 设成 `true`。
  你自己设过同名变量、值不一样时不写；「撤销」只删这两条，登录提示还原成原来的值；注释和别的设置不动。
- **Codex 会话归桶**（2026-10-25 起）：在你**逐个勾选**某个 Codex 目录（中转环境、官方 `~\.codex` 或官方槽位）里的「桶」、再确认一次之后，
  把那些会话的 `model_provider` 改成那个目录当前用的那一个 —— 改的是 `sessions\` / `archived_sessions\` 下会话文件里 `session_meta`
  那一行，和 `state_5.sqlite` 的 `threads` 表。**改之前先备份**（会话文件原样复制、状态库整份拷贝，放在面板自己的目录
  `backups\codex-history\` 下），可以按备份还原（只改回那一处，之后接着聊的内容留着）。压缩过的会话（`.jsonl.zst`）不动。
  **请先关掉 Codex**：它开着时文件可能正在写，面板发现文件在处理期间被改过就停下。
- **从 Claude Code 导入线路到桌面端**（2026-10-25 起）：在你点击后，把 Claude Code 下已经绑了 Key 的线路复制一份给 Claude 桌面端
  （同一站点、分组、同一把 Key，Key 仍只在面板里，桌面端经本机路由）。只在面板自己的数据库里加线路，不写任何软件的配置。
- **聚合模型写进客户端配置**（2026-10-26 起，开了聚合模型时）：保存路由设置、改动名单里的线路、面板启动时，面板把聚合的模型
  写进面板中转环境目录里那几份配置 —— Claude Code 的 `settings.json`（`modelPicker`）、桌面端的 `claude_desktop_config.json`
  （`inferenceModels`）、Codex 的模型目录 `qb-gate-model-catalog.json` 与 `config.toml` 里指向它的 `model_catalog_json`。
  只增删面板自己那几行，你自己写的不动；写的都是模型名，没有 Key。为了让 Codex 的目录带上 Codex 自带的模型，
  面板会**在本机运行你装的 Codex 命令行** `codex debug models --bundled`（不联网、不登录，只把它自带的模型列表打出来）；
  找不到命令行就不写 Codex 的目录。

中转站功能里有一个默认只监听 `127.0.0.1` 的**本机 API 路由器**。它存在的理由只有
一个：让客户端把地址指向本机之后，**切换上游中转站时不必重启客户端**。

把它和「代理软件」分开说清楚 —— 它：

- 只转发**明确指向它自己**的那些 API 请求，目的地是**你自己填进去的**中转站地址；
  当前那条线在把回复交给客户端之前失败时，这一发会改用**你自己排进派单顺序的**下一条线
  （自动故障转移，默认开，可以关；只在你添加的中转线路之间换，**不碰官方账户**，官方 Codex 那条线永不换线）；
- **它不**修改系统代理设置，**不**接管任何其他程序的流量，
  自身**没有**「全局代理」「断网即停」「流量绑定」这类开关（面板另有几件
  会改动系统网络配置的功能，跟本机路由无关，见下面 §5.2）；
- 你可以让**中转线路**的那些请求经**你自己填的**出站代理（HTTP / SOCKS5，通常是你本机已经在跑的那个）出去；
  默认不走代理。官方 Codex 那条线**永远直连**，不经任何代理。代理地址里的用户名密码只存在本机，界面和日志里看不到；
- **默认只绑回环地址**，不对局域网或公网开放。你可以在「路由设置 · 网络」里把它开到所有网卡上
  （给 WSL、局域网里你自己的别的机器用）：那时**从别的机器来的每一个请求都必须带随机的路由口令**，
  不带或带错一律拒绝；官方 Codex 那条线不给别的机器用。**拿到口令的人就能用你的中转线路额度** ——
  只在你信得过的网络里开，口令可以随时换掉。开的时候 Windows 防火墙会询问一次。

也就是说，它是一个 API 路由器，**不是翻墙工具** —— 它不会让你访问到你的网络
本来访问不到的地方（出站代理是你自己已经在用的那个）。你填进去的中转站地址能否连通、是否合法，仍然由你自己负责。

### 5.2 关于会修改系统网络配置的功能

下面几件事会改动系统或浏览器的网络配置。它们与「翻墙」是两回事 ——
它们不提供任何你本来没有的网络通路，只是**防止已有的通路绕开你设定的出口**：

| 功能                                         | 做什么                                                                                                   | 边界                                                                                                                      |
| -------------------------------------------- | -------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| **禁用本机 IPv6**（0.22.1 起，**默认开启**） | 启动面板时关闭整机网卡的 IPv6 绑定（含隐藏、虚拟网卡），按需请求管理员授权                               | 位于 IP 纯净度中；关闭开关时恢复各网卡原设置，退出面板后保留当前状态；失败或已移除网卡的原值会保留供重试恢复              |
| **浏览器出站锁**                             | 给你点名的那一个浏览器加 Windows 防火墙**出站**规则：只许走你指定的 VPN / TUN 接口，物理网卡直连一律拦掉 | 只按该浏览器的 exe 路径生效，**不碰任何其它程序**；只加出站规则，不改路由表、不做转发；面板里看得到当前规则，也能一键撤销 |
| **系统代理修改**                             | 在你点了「修」之后修改系统代理设置，改之前记录原值                                                       | **不自动改、不在启动时改**，只在你当次点了才改；面板里能回滚到原值                                                        |
| **浏览器策略**（WebRTC、安全 DNS）           | 在你点击后，为当前 Windows 用户写入 Chrome 策略，限制 WebRTC 暴露本机地址、调整安全 DNS                  | 只写当前用户（HKCU），**不碰整机策略**；面板里能撤销                                                                      |

必须说清楚的代价：

- **禁用 IPv6 可能短暂断网，或影响依赖 IPv6 的 Windows 功能。** 它不等于移除 Windows 内部的
  IPv6 回环，也不承诺防泄露或账户安全。卸载面板之前如需恢复，请先关闭开关并核对状态。
- **出站锁的防火墙规则不随面板退出而消失。** 面板关掉、甚至卸载之后规则仍然在，
  浏览器可能因此上不了网。撤销入口在面板里，**卸载面板之前请先撤销**。
- **改系统代理可能当场断网。** 改错了、或者代理本身没起来，受影响的是整台机器上
  所有跟随系统代理的程序，不只是那一个浏览器。
- 这些功能都**不会**让你访问到你的网络本来访问不到的地方，也**不能**证明你的
  网络接入行为合法。

但必须明确：

- **国际联网的信道与接入方式在中国大陆有专门的行政法规要求。**
  本项目提供检测与配置工具的行为，**不能**证明、也不试图证明使用者的网络接入行为合法。
- **你的网络接入是否合法，由你自己负责。** 请自行确认你使用的接入方式符合
  你所在地的法律法规。
- 本项目**不对**任何网络服务商作出推荐性的合规判断。

### 5.3 关于官方 Codex 的 turn-state 注入（实验功能，默认关闭）

> **这是一个实验功能，默认关闭，只作用于 OpenAI Codex，与 Anthropic Claude 无关。**
> 打开它不代表能改善任何东西。

OpenAI Codex 的服务器会在响应头里回一张加密的 `X-Codex-Turn-State`「纸条」，
本该由客户端在下一轮带回。打开这个功能后，QB Gate 的本机路由会：

- **被动采集**你自己请求的响应里本就带回的这张纸条（不额外发请求、不消耗多余额度）；
- 在你的客户端**自己没带**时，把采到的那张补注进去；客户端自己带了就**保留它的**，不覆盖。

**必须说清楚的边界：**

- **它只读纸条的长度外形，不解密、不验签。** 长度（个人约 292、Team 约 332）**只是经验筛选口径，
  不是 OpenAI 公布的质量指标**：符合不代表模型「满血」，不符合也不能断定降智。**它不增加你的账号额度。**
- **它不换账户、不读限流/额度、不换出口。** 与本文件其它承诺一致：账户只由你手动切换，
  任意时刻只有一个账户激活，且必须是你本人拥有的账户。
- **开启识别会临时修改你当前激活的 Codex 账户槽位的 `config.toml`**（v0.24.7 起）：先备份，
  只改 `model_provider` 与一个 `[model_providers.qb_turnstate]` 表，把**这一个槽位**的 Codex
  指向本机路由；**登录文件（`auth.json`）一个字不碰、不复制、不另起第二个 Codex**。关闭时
  反向恢复这两处；本程序下次启动若发现上次没关干净，会自动关闭并恢复。
- **开启后你的 ChatGPT 登录凭证（OAuth）会随你自己的请求流经本机路由。**
  本机路由**仍然只绑 `127.0.0.1`、不修改系统代理、不做链式转发**（见 §5.1）——
  它只把你自己的请求转发到官方端点。这是「本机路由不承载官方身份」那条默认边界的
  **唯一受控例外**，只为这个实验功能、且只在你手动开启后成立。
- **操纵会话状态可能触碰服务商条款。** 是否使用、是否合规，由你自行判断并承担后果
  （见 §4、§11）。本项目对账户状态不作任何承诺，见 §3。

**关于扩展中心里的「Codex 出站与换出口」条目（v0.24.2）：** 它接入的是一个**你自己安装的
第三方程序**（ccodex-sleep-state，GPL-3.0），本程序只负责启动、停止和打开它的网页面板，
不内置、不复制它的代码（可从它的仓库 Releases 一键下载其发布的二进制包，按发布自带的
`SHA256SUMS` 校验；校验只防下载损坏与下错包，不代表本程序对该仓库内容作担保）。代理 / 订阅 / 机场出站，以及它那项实验性的「换出口」
能力，都由那个程序在**它自己的进程**里实现并由你在它的界面里配置 —— **本程序核心仍然
不内置代理、不换出口、不换账户**，§5.1 / §5.2 的边界不变。那个程序会接管你当前激活的
Codex 账户槽位的配置（没有槽位才是默认 `~/.codex`；退出时恢复），与上面的 turn-state 识别
不能同时开（两者都要修改同一个槽位的 Codex 配置）；它的探测会消耗
你自己的额度，且同样不增加额度、不证明模型质量。是否安装、是否使用、是否合规，
由你自行判断并承担后果。

  访问令牌、刷新令牌与过期时刻，请求 Code Assist `loadCodeAssist` / `retrieveUserQuota`，只取模型名、
  剩余比例与重置时刻。访问令牌过期时（2026-09-23 起）用刷新令牌向 `oauth2.googleapis.com`
  换一张新的，**只放内存**，不写回 `oauth_creds.json`；换新要带的客户端标识从你本机装的
  `@google/gemini-cli` 包（入口脚本及同目录的 `.js`）里现读，用完即丢。
  令牌不写入日志、快照或前端；失败时显示原因，不显示 0%。
- **反重力 Hub · 账户**（v0.32.0）：读 Windows 凭据管理器里那一条
  `gemini:antigravity`（反重力 Hub 自己写的）。打开反重力页时**只取其中 `id_token` 的载荷**
  解出邮箱与验证状态 —— 一次本机 base64 解码，**零网络**；访问令牌与刷新令牌只在你点
  Hub 那一格的「刷新」时读（见上面「联网额度」）。这是面板**唯一一处读取凭据管理器内容**的地方；
  0.31.0 之前它只问「那条在不在」。不想让它读，就不要打开反重力页。
